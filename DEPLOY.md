# Artofex — Deployment Guide

## Prerequisites

- HestiaCP server: `72.62.93.36`
- Domain: `artofexstudio.com`
- HestiaCP username: `artofex`
- PHP version: 8.3+

## Step 1: Set Up GitHub Repository

1. Create a new GitHub repository (e.g., `jand05x/architect-portfolio`)
2. Push this code to the repository:
   ```bash
   git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git
   git branch -M main
   git push -u origin main
   ```

## Step 2: Set GitHub Secrets

Go to your GitHub repo → **Settings** → **Secrets and variables** → **Actions** → **New repository secret**:

| Secret Name | Value |
|-------------|-------|
| `SFTP_HOST` | `72.62.93.36` |
| `SFTP_USER` | `artofex` |
| `SFTP_PASSWORD` | Your HestiaCP password |
| `DEPLOY_DOMAIN` | `artofexstudio.com` |

## Step 3: Set Up HestiaCP

### 3.1 Create Domain
1. Go to **Web** → **Add Domain**
2. Domain: `artofexstudio.com`
3. Enable **SSL** (Let's Encrypt — automatic)
4. PHP version: **8.3** or higher
5. Click **Add**

### 3.2 Create MySQL Database
1. Go to **DB** → **Add Database**
2. Database name: `artofex_db`
3. Username: `artofex_user`
4. Set a strong password
5. **Note the credentials** — you'll add them to `.env` on the server

### 3.3 Set Up Mail Account
1. Go to **Mail** → **Add Domain** → `artofexstudio.com`
2. **Add Account** → `info@artofexstudio.com` → set a password
3. **SMTP credentials:**
   - Host: `mail.artofexstudio.com` (or `72.62.93.36`)
   - Port: `587` (TLS)
   - Username: `info@artofexstudio.com`
   - Password: (what you set above)

### 3.4 Point DNS
- Go to your domain registrar (where you bought `artofexstudio.com`)
- Set **A record**: `@` → `72.62.93.36`
- Wait for DNS propagation (5-30 minutes)

## Step 4: Deploy

Push to `main` branch — GitHub Actions deploys automatically:

```bash
git add .
git commit -m "Deploy to production"
git push origin main
```

Monitor deployment: GitHub repo → **Actions** tab.

## Step 5: Configure `.env` on Server

After first deploy, use HestiaCP **File Manager** to edit `/home/artofex/web/artofexstudio.com/public_html/.env`:

```
APP_NAME=ARTOFEX
APP_ENV=production
APP_DEBUG=false
APP_URL=https://artofexstudio.com
APP_KEY=base64:... (auto-generated by deploy)

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=artofex_db
DB_USERNAME=artofex_user
DB_PASSWORD=your-db-password

MAIL_MAILER=smtp
MAIL_HOST=mail.artofexstudio.com
MAIL_PORT=587
MAIL_USERNAME=info@artofexstudio.com
MAIL_PASSWORD=your-mail-password
MAIL_FROM_ADDRESS=info@artofexstudio.com
MAIL_ENCRYPTION=tls
```

## Step 6: Run Initial Setup

Use HestiaCP **Web Terminal** (under user settings) or SSH:

```bash
cd /home/artofex/web/artofexstudio.com/public_html
php artisan migrate --force
php artisan config:cache
php artisan route:cache
php artisan view:cache
```

## Step 7: Verify

Visit `https://artofexstudio.com` — the site should load.

Admin panel: `https://artofexstudio.com/admin`


## Troubleshooting

### 500 Error
- Check logs: `storage/logs/laravel.log`
- Clear caches via web terminal: `php artisan optimize:clear`
- Verify `.env` has correct credentials

### Images Not Showing
- Run: `php artisan storage:link`
- Check permissions: `chmod -R 775 storage/`

### Contact Form Not Sending
- Verify SMTP credentials in `.env`
- Check mail server logs in HestiaCP → Mail → `info@artofexstudio.com` → Logs

### CSS/JS Not Loading
- Run: `npm run build && git push`
- Or manually rebuild: `npm run build` locally and push
